# Dattatri Portfolio

A modern responsive portfolio built with React + Vite.

## 1. Install Node.js
Install the current LTS version of Node.js from https://nodejs.org/

## 2. Open this folder in VS Code

## 3. Install dependencies
```bash
npm install
```

## 4. Start the website
```bash
npm run dev
```

Open the local URL shown by Vite, usually:
http://localhost:5173

## 5. Build for deployment
```bash
npm run build
```

## Important edits before publishing

Open `src/main.jsx` and replace:
- `your-email@example.com` with your real professional email
- GitHub placeholder URL with your GitHub profile
- LinkedIn placeholder URL with your LinkedIn profile
- Project links in the projects array with real live/GitHub links

You can also add screenshots or a profile photo later.

## Suggested deployment
- Vercel
- Netlify
- Render Static Site

The generated `dist` folder after `npm run build` is the production build.
